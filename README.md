# System Design Masterclass

An interactive curriculum for learning practical system design through architecture walkthroughs, simulations, trade-off analysis, quizzes, and interview practice.

## Live app

[Open System Design Masterclass](https://system-design-masterclass-iota.vercel.app/)

## What’s inside

- Guided modules covering system-design foundations through advanced infrastructure
- Interactive architecture flows and component inspection
- Hands-on labs for consistent hashing, rate limiting, Snowflake IDs, tries, quorum, fanout, and order books
- Capacity estimation workbench, quizzes, and a timed interview whiteboard
- Responsive interface with light and dark shadcn-inspired themes
- Local progress tracking for completed modules and theme preference

## Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

## Stack

React, TypeScript, Vite, and Lucide icons.
